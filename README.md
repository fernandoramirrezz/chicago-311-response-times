# chicago-311-response-times

This project looks at whether the time it takes the city to close a 311
request depends on the community area where the request was made, after
accounting for the request type and time of year.

## Data
311 Service Requests from the Chicago Data Portal, pulled through the
API in six short windows between July 2025 and May 2026 (35,146 closed
requests after cleaning).

## Files
- progress_report.ipynb: data cleaning, visualizations, and ML analyses
